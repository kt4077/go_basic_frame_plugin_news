# 新闻资讯插件 v0.0.3 更新说明

## 版本类型

向后兼容的用户端 UI 修订版本。

## 主要内容

- 新闻列表改为左侧封面、右侧标题与摘要的紧凑信息流；
- 列表底部统一展示带图标的分类、发布时间和阅读数；
- 分类导航支持大量分类横向滚动、当前分类自动定位和超长名称省略；
- 新闻详情改为微信公众号式内容排版，突出标题、作者、时间、阅读量、分类、来源和正文；
- 亮色、暗色和跟随系统主题继续使用宿主主题变量。

## 数据库与 API

- 不新增数据库迁移，继续使用 `0.0.2` 数据库结构；
- 不新增或删除接口字段；
- 与 `0.0.2` 数据完全兼容。

## 升级操作

先在管理端停用插件并重启服务，然后执行：

```bash
go run . plugin upgrade /path/go_basic_frame_plugin_news-v0.0.3.zip \
  --server-root . \
  --admin-root ../admin_client \
  --user-root ../user_client \
  --config ./config.yaml \
  --apply-database
```

本版本没有待执行 DDL，`--apply-database` 用于原子更新插件版本、安装日志和相关元数据。升级后重新构建用户端，并重启管理端 API、用户端 API，再启用插件。

## 回滚说明

本版本没有数据库变化，可以恢复 `0.0.2` 源码和插件版本记录回滚；操作前仍建议备份并先停用插件。
