# 新闻资讯插件 v0.1.0 更新说明

## 版本定位

本版本新增完整互动能力，属于向后兼容的次版本升级。原有分类、文章、作者来源、浏览量和用户端阅读能力保持不变。

## 新增功能

- 文章、评论点赞与取消点赞；
- 分享发起记录与文章分享计数；
- 一级评论、层级回复、评论图片和评论点赞；
- 管理端文章列表评论入口、右侧评论抽屉、根评论分页和回复分页；
- 管理端评论待审核、显示、关闭状态维护；
- 用户端评论、回复、图片上传、点赞与分享接口联调。

## 兼容和安全

- 新业务统一使用 `uid`，不向用户端暴露数据库主键；
- 会员身份仅从登录令牌取得并以 `sys_member.sn` 关联，客户端不能伪造会员标识；
- 写操作具备 Redis 频率限制、数据库事务、幂等请求标识与唯一索引；
- 用户端响应仅返回展示所需字段，账号、IP 只在管理端脱敏展示。

## 升级

```bash
go run . plugin upgrade /path/go_basic_frame_plugin_news-v0.1.0.zip \
  --server-root . \
  --admin-root ../admin_client \
  --user-root ../user_client \
  --config ./config.yaml \
  --apply-database
```

升级后重新执行 `go run . plugin generate --server-root .`，完成代码检查和三端构建，再重启管理端 API 与用户端 API。该命令用于重新生成插件注册文件，不替代升级命令。

## 回滚

本版本新增数据表和文章列。代码可回滚，但不能在未备份的情况下直接删除新表或新列；若需要彻底回退，应先停用插件，备份互动数据，再按数据库变更审核流程处理。
