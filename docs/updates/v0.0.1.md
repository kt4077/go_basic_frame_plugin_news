# 新闻资讯插件 v0.0.1 更新说明

## 版本类型

重新规划版本后的首个完整基线版本。

## 主要内容

- 合并原 `1.0.0` 至 `1.1.4` 的全部分类、文章、富文本、封面、发布、启用状态和阅读量能力；
- 合并管理端和用户端完整 API 文档、数据库说明及历史更新说明；
- 新安装直接创建最终数据库结构，不再先建基础表后追加字段；
- 支持已安装的 `1.1.0` 至 `1.1.4` 在显式确认后重建为 `0.0.1` 基线；
- 文章正文继续复用宿主 `RichTextEditor`，并适配管理端亮色、暗色主题；
- 列表封面直接展示原图，分类和文章标识创建后保持不可变。

## 数据库变化

全新安装执行 `database/migrations/0.0.1.sql` 创建最终结构。

旧版本重建基线不会重复执行 DDL，要求数据库中已经存在成功的 `1.0.0` 和 `1.1.0` 迁移记录。安装器在插件级数据库锁内原子写入 `0.0.1` 迁移记录、菜单映射、插件信息和安装日志，保留旧业务数据与历史迁移记录。

## API变化

`0.0.1` 接口能力为原历史版本能力的合并基线，完整定义见 `docs/api/v0.0.1.md`。

## 升级操作

全新安装：

```bash
go run . plugin install /path/go_basic_frame_plugin_news-v0.0.1.zip \
  --server-root . --admin-root ../admin_client \
  --config ./config.yaml --apply-database
```

已安装原 `1.1.0` 至 `1.1.4`：先备份数据库，在管理端停用插件并重启服务，然后执行：

```bash
go run . plugin upgrade /path/go_basic_frame_plugin_news-v0.0.1.zip \
  --server-root . --admin-root ../admin_client \
  --config ./config.yaml --apply-database --allow-version-rebase
```

完成后重新构建管理端与后端，重启管理端 API 和用户端 API，再启用插件。

## 兼容性与回滚

旧版本重建基线只适用于清单明确列出的历史版本，并且必须显式提供确认参数。缺少历史迁移记录时安装器拒绝执行。回滚需要同时恢复旧插件源码与 `sys_plugin` 版本记录，不建议在未备份数据库时操作。
