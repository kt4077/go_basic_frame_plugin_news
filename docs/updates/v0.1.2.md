# v0.1.2 更新说明

## 新增功能

- 管理端文章列表增加“复用资讯”图标操作；
- 点击后跳转到独立新增页面，并预填分类、标题、摘要、作者、来源、封面、正文、启用状态和排序；
- 自动生成约 11 位的可编辑短文章标识，格式为 `n + 6 位时间片 + 4 位随机值`；
- 标题增加“（复用）”提示，便于编辑人员识别，保存前可自行调整；
- 不复制原资讯主键、真实阅读、虚拟阅读及互动统计，保存后形成完全独立的新资讯。

## 权限与安全

- 复用入口沿用“文章详情”和“保存文章”权限，不增加重复权限节点；
- 复用页面只携带源文章数据库 ID 读取管理端详情，保存时固定按照新增数据提交；
- 新文章 UID 仍由服务端生成，短标识仍受服务端格式验证和数据库唯一索引约束；
- 不复制原文章的发布状态、发布时间或任何用户互动关系。

## 数据库

本版本没有数据库结构变化，不新增迁移文件，升级时无需执行 DDL。保留 `--apply-database` 参数不会产生额外迁移。

## 升级

```bash
go run . plugin upgrade ../go_basic_frame_plugin_news/go_basic_frame_plugin_news-v0.1.2.zip \
  --server-root . \
  --admin-root ../admin_client \
  --user-root ../user_client \
  --config ./config.yaml \
  --apply-database
```

升级后重新构建管理端，并重启管理端 API 与用户端 API。无需执行 `plugin generate`，除非安装后的插件注册源码被手工修改或恢复。
