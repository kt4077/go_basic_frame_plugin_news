# 新闻资讯插件 v0.0.2 更新说明

## 版本类型

向后兼容的功能新增版本。

## 主要内容

- 新闻文章新增作者、来源平台名称和来源外部链接；
- 管理端文章表单支持维护三个字段，列表支持查看作者并打开来源链接；
- 用户端资讯列表显示作者，详情展示作者与来源；
- 用户端列表采用左侧封面、右侧标题与摘要、底部分类/时间/阅读量的紧凑信息流；分类数量较多时支持横向滚动并自动定位当前项；
- 用户端详情采用微信公众号式的标题、作者、来源、发布时间、摘要引导和正文内容流排版；
- 用户端来源外链统一进入宿主受控 WebView，不执行非 HTTP/HTTPS 协议；
- 历史文章字段默认留空，不影响原有展示。

## 数据库变化

执行 `database/migrations/0.0.2.sql`，为 `plg_news_article` 增加 `author`、`source_name`、`source_url`。迁移不修改或覆盖历史数据。

## API 变化

管理端保存接口新增三个可选字段：

```json
{
  "author": "编辑部",
  "source_name": "项目官网",
  "source_url": "https://www.tutudati.com/news/plugin-release"
}
```

管理端文章响应和用户端文章响应同步返回上述字段。`source_url` 非空时必须是合法的 HTTP/HTTPS 地址。

## 升级操作

先备份数据库，在管理端停用插件并重启服务，然后执行：

```bash
go run . plugin upgrade /path/go_basic_frame_plugin_news-v0.0.2.zip \
  --server-root . \
  --admin-root ../admin_client \
  --user-root ../user_client \
  --config ./config.yaml \
  --apply-database
```

升级后重新构建管理端和用户端，并重启管理端 API、用户端 API，再启用插件。

## 回滚说明

应用 `0.0.2` 后不建议删除新增字段。代码回滚到 `0.0.1` 时新增字段会被旧代码忽略，已有文章数据仍可保留；再次升级到 `0.0.2` 时安装器根据迁移记录不会重复执行迁移。
