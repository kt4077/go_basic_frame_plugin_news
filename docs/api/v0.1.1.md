# 新闻插件 API v0.1.1

## 文章点赞

- 请求：`POST /api/auth/plugin/news/article/like`
- 鉴权：用户端登录鉴权
- 参数：`article_uid`，兼容传入文章业务 UID 或公开 slug
- 行为：服务端在事务内原子切换点赞状态，不使用 DELETE 请求
- 响应：`active` 为最新点赞状态，`count` 为最新点赞数

## 文章收藏

- 请求：`POST /api/auth/plugin/news/article/collection`
- 鉴权：用户端登录鉴权
- 参数：`article_uid`，兼容传入文章业务 UID 或公开 slug
- 行为：服务端在事务内原子切换收藏状态
- 响应：`active` 为最新收藏状态，`count` 为最新收藏数

## 互动状态

- 请求：`GET /api/auth/plugin/news/article/interaction?article_uid=...`
- 响应仅返回 `liked` 与 `collected`，不暴露会员标识和数据库主键。

## 管理端文章列表

- 请求：`GET /admin/plugin/news/article/list`
- 新增响应字段：`collection_count`
- 新增参数：`order_by`、`order`
- `order_by` 白名单：`view_count`、`virtual_view_count`、`total_view_count`、`like_count`、`share_count`、`collection_count`、`comment_count`
- `order`：`asc` 或 `desc`
