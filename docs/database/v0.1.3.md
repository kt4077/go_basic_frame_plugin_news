# 新闻插件数据库 v0.1.3

## 插件业务表

新增 `plg_news_advertisement_config`，保存核心广告 ID 与新闻展示位置的关系。

| 字段 | 说明 |
| --- | --- |
| `advertisement_id` | 引用核心 `sys_advertisement.id`，不建立物理外键 |
| `position` | `1` 新闻列表，`2` 新闻详情 |

`(advertisement_id, position)` 建立唯一索引，防止同一广告在同一位置重复配置。

## 外部数据库引用

| 检查项 | 结论 |
| --- | --- |
| 是否引用核心业务表 | 是，运行时读取 `sys_advertisement`、`sys_advertisement_plugin`、`sys_plugin`，不建立物理外键 |
| 是否引用其他插件表 | 否 |
| 是否允许 Purge | 是，Purge 只删除 `plg_news_*` 表，不删除核心广告 |
| 是否自动删除文件 | 否 |

Remove 保留新闻广告配置数据。Purge 会删除 `plg_news_advertisement_config` 及其他 `plg_news_*` 表；核心广告配置和绑定关系不受影响。
