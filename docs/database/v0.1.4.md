# 新闻插件数据库 v0.1.4

## 插件业务表

`plg_news_advertisement_config` 新增 `status` 字段和普通索引，`1` 启用、`2` 停用，默认启用。

## 外部数据库引用

| 检查项 | 结论 |
| --- | --- |
| 是否引用核心业务表 | 是，读取 `sys_advertisement`、`sys_advertisement_plugin` 和 `sys_plugin`，不建立物理外键 |
| 是否引用其他插件表 | 否 |
| 是否允许 Purge | 是，Purge 不影响核心广告数据 |
| 是否自动删除文件 | 否 |

Remove 保留数据；Purge 可删除 `plg_news_*` 表且不影响核心广告数据。
