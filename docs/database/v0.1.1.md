# 新闻插件数据库 v0.1.1

- `plg_news_article` 新增 `collection_count` 收藏计数字段。
- 新增 `plg_news_article_collection` 文章收藏记录表。
- 收藏关系使用文章 `uid` 和会员 `sn`，不使用数据库主键作为外部业务关系。
- `(article_uid, member_sn)` 唯一索引保证同一用户对同一文章只有一条收藏状态记录。
- 收藏记录与文章计数在同一事务内更新，避免并发导致数据不一致。

## 插件业务表

| 表名 | 用途 | 主要约束 |
| --- | --- | --- |
| `plg_news_article` | 新闻文章主表 | 新增 `collection_count` 收藏计数 |
| `plg_news_article_collection` | 文章收藏状态 | `uid` 唯一；`article_uid + member_sn` 唯一 |

## 外部数据库引用

| 检查项 | 结论 |
| --- | --- |
| 是否引用核心业务表 | 是，逻辑使用 `sys_member.sn` 标识当前会员，不建立物理外键 |
| 是否引用其他插件表 | 否 |
| 是否允许 Purge | 是，但必须先停用插件并完成数据库备份 |
| 是否自动删除文件 | 否，本次迁移不创建或删除文件记录 |

Remove 仅移除插件代码、菜单和安装状态，保留收藏及其他业务数据。Purge 会删除全部 `plg_news_*` 插件业务表及迁移记录，执行前必须确认不存在外部引用并完成备份。
