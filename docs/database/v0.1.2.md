# 新闻插件数据库 v0.1.2

本版本不包含数据库迁移，不调整表、字段、索引或历史数据。复用资讯通过现有新增接口写入一条独立文章记录，文章 `uid` 由服务端生成，`slug` 由管理端生成约 11 位的短标识并接受现有唯一索引校验，不复用原资讯业务标识。

## 插件业务表

沿用 v0.1.1 的全部 `plg_news_*` 插件业务表。本版本不会复制发布状态、发布时间、真实或虚拟阅读量，也不会复制点赞、收藏、分享、评论等互动记录，所有统计从零开始。

## 外部数据库引用

| 检查项 | 结论 |
| --- | --- |
| 是否引用核心业务表 | 是，互动数据逻辑使用 `sys_member.sn`，不建立物理外键；本版本未新增引用 |
| 是否引用其他插件表 | 否 |
| 是否允许 Purge | 是，但必须先停用插件并完成数据库备份 |
| 是否自动删除文件 | 否，复用资讯仅引用已有相对文件路径，不自动删除上传文件 |

Remove 仅移除插件代码、菜单和安装状态，保留插件业务数据。Purge 会删除全部 `plg_news_*` 插件业务表及迁移记录，执行前必须确认不存在外部引用并完成备份。
